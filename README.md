# CapsLock Layout

Ультралёгкое приложение для Windows 11, которое переключает раскладку **русская ↔ английская (США)** по Caps Lock. Написано на Rust и использует только Win32 API, без стороннего runtime и внешних ресурсов.

## Возможности

- Caps Lock переключает RU ↔ EN, не включая верхний регистр.
- Удержание Caps Lock не вызывает повторные переключения.
- В трее отображается увеличенный флаг текущей раскладки: России, США или Великобритании.
- Подменю **«Флаг английской раскладки»** позволяет выбрать США или Великобританию.
- Подменю **«Поведение кнопки CapsLock»** переключается между стандартным Caps Lock и изменением раскладки.
- Пункт **«Активировать плавающее окно»** показывает текущий флаг в правом нижнем углу экрана; после включения он меняется на **«Деактивировать плавающее окно»**.
- Плавающее окно остаётся поверх других окон, не забирает фокус и перемещается левой кнопкой мыши.
- Подменю **«Размер плавающего окна»** предлагает масштабы 75%, 100%, 150% и 200%.
- Пункт **«Сбросить плавающее окно»** возвращает размер 100% и положение в правом нижнем углу.
- Если сохранённые координаты находятся вне подключённых мониторов, окно автоматически возвращается на основной экран.
- Выбранные поведение, флаг, размер, состояние и координаты плавающего окна сохраняются в `HKCU\Software\CapsLockLayout` и восстанавливаются после перезапуска.
- Пункт **«Добавить в автозагрузку»** создаёт задачу планировщика Windows с запуском при входе пользователя и наивысшими правами.
- Если автозагрузка включена, пункт меняется на **«Убрать из автозагрузки»** и удаляет эту задачу.
- При каждом запуске приложение заново регистрирует задачу автозагрузки, поэтому путь к exe и настройки задачи всегда актуальны.
- В режиме **«CapsLock по умолчанию»** клавиша работает стандартно для Windows.
- Пункт **«Скрыть из трея»** скрывает иконку без завершения приложения.
- Повторный запуск восстанавливает скрытую иконку; второй постоянный процесс не создаётся.
- Пункт **«Выход»** полностью завершает приложение.

## Скачать и запустить

Rust и установка не нужны — приложение распространяется одним готовым EXE-файлом.

1. Скачайте [`capslock-layout.exe`](https://github.com/vitacbka/capslock_layout/releases/download/v0.1.1/capslock-layout.exe) из [релиза v0.1.1](https://github.com/vitacbka/capslock_layout/releases/tag/v0.1.1).
2. Сохраните файл в постоянную папку, из которой будете запускать приложение.
3. Запустите EXE двойным кликом. Если Windows покажет запрос UAC, подтвердите его.
4. Главного окна нет: в области уведомлений появится флаг текущей раскладки. Если его не видно, откройте скрытые значки в системном трее.
5. Нажимайте Caps Lock для переключения RU ↔ EN и используйте правый клик по флагу для открытия меню.

Для работы в административных окнах, включая Windows Terminal и PowerShell, приложению нужны повышенные права. При запуске без них оно автоматически перезапускается через задачу планировщика `CapsLockLayout` с наивысшими правами.

## Требования

- Windows 11 x64.
- Русская и английская (США) раскладки должны быть установлены в Windows.
- Запуск с правами администратора. Манифест приложения запрашивает их автоматически через UAC: это необходимо для перехвата клавиш в административных окнах, включая Windows Terminal и PowerShell.

## Сборка из исходников

Установите [Rust](https://rustup.rs/), затем выполните:

```powershell
cargo build --release
```

Готовый файл появится по пути:

```text
target\release\capslock-layout.exe
```

Запустите его и подтвердите запрос UAC. Консольное окно приложение не открывает.

## Использование

1. Нажимайте Caps Lock для смены раскладки.
2. Щёлкните правой кнопкой по флагу в трее для открытия меню.
3. В **«Поведение кнопки CapsLock»** выберите **«CapsLock по умолчанию»**, чтобы вернуть обычный режим, или **«Изменение раскладки»** для RU ↔ EN.
4. В **«Флаг английской раскладки»** выберите США или Великобританию.
5. Включите **«Активировать плавающее окно»**, чтобы видеть флаг на экране; повторный выбор скрывает его.
6. Выберите масштаб в **«Размер плавающего окна»** и перетаскивайте окно левой кнопкой мыши в нужное место.
7. Если окно потерялось, выберите **«Сбросить плавающее окно»**.
8. Выберите **«Добавить в автозагрузку»** для запуска при входе в Windows. Повторный выбор **«Убрать из автозагрузки»** отменяет его.
9. Если иконка скрыта, запустите приложение ещё раз, чтобы вернуть её.

Автозагрузка использует задачу `CapsLockLayout` в планировщике заданий Windows. Приложение перерегистрирует её при каждом запуске, поэтому после перемещения exe обновлять задачу вручную не нужно. Задача запускается и от батареи, и после пропущенного входа в систему.

## Память и оптимизация

Измерение на Windows 11 после запуска и после 20 переключений:

| Метрика | До | После |
|---|---:|---:|
| Private Memory | 1476 КиБ | 1476 КиБ |
| Working Set | 9220 КиБ | 9264 КиБ |

Private Memory — выделенная процессу память. Working Set дополнительно включает страницы системных DLL и не равен утечке или исключительному расходу приложения. Числа зависят от версии Windows и загруженных системных компонентов.

Уже применено:

- В обработчике Caps Lock нет динамических выделений памяти: список раскладок хранится в фиксированном массиве на 32 элемента.
- Нет фонового цикла с постоянным опросом; приложение спит в очереди сообщений Windows.
- Флаги рисуются через GDI и не требуют PNG, файлов ресурсов или графических библиотек.
- Release-сборка использует LTO, одну codegen-unit, оптимизацию размера и удаление символов.
- Повторные нажатия при удержании клавиши отфильтровываются.

Возможные дальнейшие варианты:

- Заменить короткоживущие строки меню на статические UTF-16-массивы. Это уберёт несколько выделений при открытии меню, но почти не изменит постоянное потребление.
- Перейти на `no_std` и собственный entry point. Это может уменьшить RTL и размер файла, но добавит unsafe-код, усложнит поддержку и **не гарантирует private-память меньше 1 МиБ**.
- Кэшировать обе иконки вместо пересоздания. Это снизит работу GDI при переключении, но немного увеличит постоянный расход памяти, поэтому сейчас не применяется.
- `SetProcessWorkingSetSize` может визуально уменьшить Working Set, вытеснив страницы Windows. Это не снижает реальную потребность в памяти и может ухудшить производительность, поэтому специально не используется.
