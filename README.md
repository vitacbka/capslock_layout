# CapsLock Layout

Ультралёгкое приложение для Windows 11, которое переключает раскладку **русская ↔ английская (США)** по Caps Lock. Написано на Rust и использует только Win32 API, без стороннего runtime и внешних ресурсов.

## Возможности

- Caps Lock переключает RU ↔ EN, не включая верхний регистр.
- Удержание Caps Lock не вызывает повторные переключения.
- В трее отображается флаг текущей раскладки: России или США.
- Пункт **«Переключать раскладку»** включает и выключает обработку Caps Lock.
- После выключения Caps Lock возвращается к стандартному поведению Windows.
- Пункт **«Скрыть из трея»** скрывает иконку без завершения приложения.
- Повторный запуск восстанавливает скрытую иконку; второй постоянный процесс не создаётся.
- Пункт **«Выход»** полностью завершает приложение.

## Требования

- Windows 11 x64.
- Русская и английская (США) раскладки должны быть установлены в Windows.
- Запуск с правами администратора. Манифест приложения запрашивает их автоматически через UAC: это необходимо для перехвата клавиш в административных окнах, включая Windows Terminal и PowerShell.

## Сборка

Установите [Rust](https://rustup.rs/), затем выполните:

```powershell
cargo build --release
```

Готовый файл появится по пути:

```text
target\release\capslock-layout.exe
```

Запустите его и подтвердите запрос UAC. Консольное окно приложение не открывает.

## Использование

1. Нажимайте Caps Lock для смены раскладки.
2. Щёлкните правой кнопкой по флагу в трее для открытия меню.
3. Снимите отметку **«Переключать раскладку»**, чтобы вернуть обычный Caps Lock.
4. Если иконка скрыта, запустите приложение ещё раз, чтобы вернуть её.

## Память и оптимизация

Измерение на Windows 11 после запуска и после 20 переключений:

| Метрика | До | После |
|---|---:|---:|
| Private Memory | 1476 КиБ | 1476 КиБ |
| Working Set | 9220 КиБ | 9264 КиБ |

Private Memory — выделенная процессу память. Working Set дополнительно включает страницы системных DLL и не равен утечке или исключительному расходу приложения. Числа зависят от версии Windows и загруженных системных компонентов.

Уже применено:

- В обработчике Caps Lock нет динамических выделений памяти: список раскладок хранится в фиксированном массиве на 32 элемента.
- Нет фонового цикла с постоянным опросом; приложение спит в очереди сообщений Windows.
- Флаги рисуются через GDI и не требуют PNG, файлов ресурсов или графических библиотек.
- Release-сборка использует LTO, одну codegen-unit, оптимизацию размера и удаление символов.
- Повторные нажатия при удержании клавиши отфильтровываются.

Возможные дальнейшие варианты:

- Заменить короткоживущие строки меню на статические UTF-16-массивы. Это уберёт несколько выделений при открытии меню, но почти не изменит постоянное потребление.
- Перейти на `no_std` и собственный entry point. Это может уменьшить RTL и размер файла, но добавит unsafe-код, усложнит поддержку и **не гарантирует private-память меньше 1 МиБ**.
- Кэшировать обе иконки вместо пересоздания. Это снизит работу GDI при переключении, но немного увеличит постоянный расход памяти, поэтому сейчас не применяется.
- `SetProcessWorkingSetSize` может визуально уменьшить Working Set, вытеснив страницы Windows. Это не снижает реальную потребность в памяти и может ухудшить производительность, поэтому специально не используется.

## Проверка

```powershell
cargo test
cargo clippy --release -- -D warnings
```

Отдельно проверены административный Windows Terminal/PowerShell, восстановление стандартного Caps Lock, скрытие и восстановление иконки, завершение второго экземпляра и стабильность private-памяти после серии переключений.
